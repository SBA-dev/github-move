# Guides fondamentaux pour l'enseignement (Eduscol)

Déposer ici les PDF des guides fondamentaux téléchargés sur
https://eduscol.education.gouv.fr/6681/les-guides-fondamentaux-pour-l-enseignement
(le site bloque les téléchargements automatiques depuis les serveurs : on les télécharge depuis un navigateur).

Ils servent à écrire les leçons de la bibliothèque (`scripts/lecons/`) en suivant la façon d'enseigner
recommandée : progression, exemples types, erreurs fréquentes.
